The first release of Doorman Trainer: a Deadlock custom game mode for practising Doorman's kidnap.

**Download `DoormanTrainer-win-Setup.exe` below**, run it, then double-click **Doorman Trainer** on your desktop. Deadlock opens straight into the trainer. Launch Deadlock from Steam as usual to play normally.

- **Ladder**: 10 levels, from a target standing still to a full fight.
- **Endless**: kidnap every enemy before the clock runs out, wave after wave. Best scores saved.
- **Mid-Boss**: hold the Mid-Boss while the enemy team takes it, kidnapping them out of the pit.
- **Practice**: your own setup: enemies, allies, behaviour, difficulty, heroes.
- Starting build with Vortex Web, quick retry and next keys, short cooldown switches, Invincible, stats.

Windows will warn you the first time because the installer isn't code-signed: click **More info → Run anyway**.

`DoormanTrainer-win-Portable.zip` is the same thing without installing: unzip it and run `Play.cmd`.
