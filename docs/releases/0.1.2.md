**Download `DoormanTrainer-win-Setup.exe` below** and run it once. From now on the trainer updates itself.

- **Updates itself.** Each time you start Doorman Trainer, it checks for a new version and installs it before starting. Offline, it just starts the version you have.
- **Closes with the game.** Quit Deadlock and the trainer stops, and its window closes by itself.
